Hilbert’s program (1920s)

ensuring the formal system is consistent1, complete2, and
decidable3.
1No contradiction.

λ-calculus
A (universal) model of computation based on anonymous
functions:
λx.y
Valid terms defined inductively by:
▶Variables: x, y, z, f , . . .
▶Abstraction: λx.y creates the function x 7→y
▶Application: fx applies the function f to x
Examples:
λx.x
λf .λx.fx
λf .λx.f (f (fx)))
λx.λy.λz((xz)(yz))
Note: Variables are not typed!

Normalization
Expressions of the form (λx.y)z can be reduced:
(λx.xx)y →yy
(λx.λy.x)z →λy.z
A λ-term that cannot be reduced is in normal form:
λf .λx.fx
λf .λx.f (f (fx)))
λx.λy.λz((xz)(yz))
Strong Normalization
A λ-term in strongly normalizing if any possible sequence of
reductions terminates in finite time to the normal form.
Counter-example: (λx.xx)(λx.xx)

Typing
Given types σ, τ, define the function type:
σ →τ
Terms are typed inductively by:
▶Variables: x : σ, y : τ, . . .
▶Abstraction: λx.y with x : σ and y : τ has type σ →τ
▶Application: fx, defined only if f : σ →τ and x : σ,
has type τ
This is called simply typed λ-calculus.
Strong Normalizing Theorem (Curry, 1930s)
Simply typed λ-calculus is strongly normalizing.
Note: The term (λx.xx)(λx.xx) cannot be typed!
