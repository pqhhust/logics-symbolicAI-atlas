About Description Logics
●Description Logics (DLs) - knowledge representation 
formalisms that
○represent the knowledge of an application domain (the world)
○by deﬁning the relevant concepts of the domain (its 
terminology)
○and then using these concepts to specify properties of 
individuals occurring in the domain (the world description).
●Inferences: classiﬁcation of
○concepts - subconcept/superconcept relationships 
(subsumption)
○individuals - whether a given individual is always an instance of 
a concept

Syntax of DL Concept Description
A, B, C, D → atomic concepts
R → atomic role
Basic constructors (AL):
●
⊤ : universal concept (all individuals) (Top concept)
●
⊥ : bottom concept (no individuals)
●
¬A : atomic negation (only for atomic concepts)
●
C ⊓ D : intersection
●
∀R.C : value restriction (all R-successors are in C)
●
∃R.⊤ : limited existential quantification
Extensions:
●
ALU: adds union (C ⊔ D)
●
ALE: adds full existential restriction (∃R.C)
●
ALC: adds full negation (¬C)
●
ALN: adds number restrictions (≤n R, ≥n R)
AL ⊆ ALE ⊆ ALC ⊆ SHOIN ⊆ SROIQ (OWL 2 DL)

Semantics
Semantics of DL
●
An interpretation 𝕀 = (Δᴵ, ⋅ᴵ) consists of:
○
a domain Δᴵ (non-empty set)
○
an interpretation function ⋅ᴵ that maps:
■
each atomic concept A → a subset Aᴵ ⊆ Δᴵ
■
each atomic role R → a relation Rᴵ ⊆ Δᴵ × Δᴵ
●
The semantics of complex expressions are defined recursively:
○
(C ⊓ D)ᴵ = Cᴵ ∩ Dᴵ
○
(¬C)ᴵ = Δᴵ \ Cᴵ
○
(∀R.C)ᴵ = { x ∈ Δᴵ | ∀y, (x,y) ∈ Rᴵ → y ∈ Cᴵ }
○
(∃R.C)ᴵ = { x ∈ Δᴵ | ∃y, (x,y) ∈ Rᴵ ∧ y ∈ Cᴵ }

Terminologies (TBox)
●
Defines relationships between concepts (and roles).
●
Axioms:
○
Inclusion: C ⊑ D (“C is a subclass of D”) 
○
Equivalence: C ≡ D (“C and D have the same instances”) 
●
If T is a set of axioms, then I satisﬁes T iﬀ I satisﬁes each element of T 
– I is a model of T
○
I ⊨T iff ∀(C⊑D or C≡D) ∈T, I ⊨ that axiom. So a model of T is an 
interpretation in which all the inclusions and equivalences in T 
hold.
○
Example:
○
If T = { Parent ⊑ Person, Mother ≡ Woman ⊓ ∃hasChild.Person },
○
then 𝕀 is a model of T if both those relationships are true in 𝕀.

Reasoning tasks for TBox
▪Satisﬁability: A concept C is satisﬁable with respect to T if 
there exists a model I of T such that CI is nonempty (I is 
a model of C)
▪Subsumption: A concept C is subsumed by a concept D 
with respect to T if CI ⊆DI for every model I of T
C ⊑D    or    T|= C ⊑ D.
▪Equivalence: Two concepts C and D are equivalent with 
respect to T if CI = DI for every model I of T
C ≡T D    or    T |= C ≡ D
▪Disjointness: Two concepts C and D are disjoint with 
respect to T if CI ∩ DI = ∅ for every model I of T

Properties
Reduction to Subsumption
▪C is unsatisﬁable ⇔ C is subsumed by ⊥ 
▪C and D are equivalent ⇔ C is subsumed by D and D is 
subsumed by C
▪C and D are disjoint ⇔ C ⊓ D is subsumed by ⊥
Reduction to Unsatisﬁability
▪C is subsumed by D ⇔ C ⊓ ¬D is unsatisﬁable 
▪C and D are equivalent ⇔ both (C ⊓ ¬D) and
(¬C ⊓ D) are unsatisﬁable
▪C and D are disjoint ⇔ C ⊓ D is unsatisﬁable

Reasoning tasks for ABox
2. Instance check
a. An assertion C(a) is entailed by A if ∀I that satisﬁes A 
also satisﬁes C(a) (A|= C(a))
A|= C(a) iﬀ A ∪ {¬C(a)} is inconsistent 
3. Retrieval problem
a. Given an ABox A and a concept C, ﬁnd all individuals a 
such that A|= C(a)
4. Realization problem
a. Given an individual a and a set of concepts, ﬁnd the 
most speciﬁc concepts C from the set such that A|= C(a)
The most speciﬁc concepts are those that are minimal with 
respect to the subsumption ordering

The triggering phase
●Three inference algorithms :
○Forward chaining (data driven)
■to deduce a particular fact: the rules whose premises are known are triggered - up to - 
the fact to be deducted is also known - or that no rule can be triggered any more
○Backward chaining (goal oriented)
■start from the fact to prove, 
■search for all the rules that conclude on that fact, 
■draw up a list of facts that need only be proved in order for them to be triggered and 
then 
■apply recursively the same mechanism to the facts contained in those lists
■These facts in turn become facts to be proven. 
■Recursion stops when the goal to prove belongs to the fact base
