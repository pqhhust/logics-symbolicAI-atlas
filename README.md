# Symbolic AI Exam Atlas

A public written-exam review atlas for CSC_5AI01_TP (2026–2027):

- 7 topic guides, 112 worked written exercises and 7 interactive examples.
- 6 complete 20-point practice papers, including 2 hard challenge papers.
- 8 lecture decks and 3 course reference handouts.
- Per-browser profiles, notes, bookmarks, confidence tracking and JSON export/import.

## Publish

In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**. The site uses plain HTML/CSS/JS and `.nojekyll`; no build step or API secrets are needed.

Expected URL: https://pqhhust.github.io/logics-symbolicAI-atlas/

The lecture files retain their original authorship. The fuzzy/PSL decks include Fabian Suchanek’s CC-BY attribution. Newly authored exercises and mock papers are study material, not official exam papers. Historical exam links are identified separately from the current syllabus.

Device-only notebooks remain available. Private-link notebooks use a separate backend and restore notes and progress on any device holding the secret link. Anyone with a private link can access that notebook; keep it safe. No private notes or bearer tokens are committed to this repository.
